# Roadmap orientativo

No es una autorización de implementación.

## Prioridad sugerida 1 — Confianza de la base

- Resolver observaciones de integridad y permisos de proyectos.
- Añadir pruebas reales para usuarios, proyectos y espacios.
- Definir la política pública de páginas y QR.

## Prioridad sugerida 2 — Operación

- Preparar configuración reproducible de desarrollo/pruebas.
- Revisar migraciones versionadas, medios, respaldos y despliegue.
- Decidir correo real y protección de intentos cuando el entorno lo necesite.

## Prioridad sugerida 3 — Evolución funcional

- Nuevos requerimientos de usuarios sobre proyectos, espacios y sensores.
- Métricas o integraciones nuevas solo mediante specs con unidades, permisos y evidencia.

Cada elemento debe convertirse en spec o tareas de una spec existente antes de programarse.
